# Politique de confidentialité — Jalon

*Dernière mise à jour : 5 novembre 2026*

Jalon (anciennement Chantier Élec) est une application pour les artisans en électricité, plomberie et peinture : chantiers, pièces, tableau électrique, matériel, devis, factures et suivi des travaux.

## Données collectées

**Aucune.** L'application ne crée pas de compte et n'envoie rien sur internet. Elle ne contient ni publicité ni outil de mesure d'audience.

## Données enregistrées sur le téléphone

Tout ce que vous saisissez reste sur votre téléphone, dans l'espace privé de l'application :
- les chantiers, pièces, tableaux, étapes, heures et réserves ;
- les coordonnées de vos clients que vous saisissez pour les devis et factures, les autres contacts et les codes d'accès de vos chantiers ;
- vos devis, factures, prix et les réglages de votre entreprise ;
- les photos, signatures et notes vocales prises dans l'application.

Ces données sont supprimées si vous désinstallez l'application. La sauvegarde Android du téléphone peut les inclure, selon vos réglages Google.

## Ce qui quitte le téléphone, et seulement à votre demande

- **Documents PDF** (devis, factures, schémas…) : uniquement quand vous choisissez de les envoyer ou de les imprimer, vers l'application que vous choisissez.
- **Fichiers de sauvegarde** : uniquement dans le dossier que vous choisissez (par exemple Google Drive).
- **Liste de matériel** : uniquement quand vous l'envoyez à un fournisseur.
- **Recherche de prix** : quand vous touchez « Chercher le prix sur internet », le nom et la référence de l'article (rien d'autre) sont envoyés au moteur de recherche de votre téléphone.

## Vérification des nouvelles versions

À chaque ouverture (une fois par minute au plus), l'application lit le fichier `versions.json` publié sur sa page de téléchargement, https://dat00udev-sys.github.io/jalon-distribution/versions.json, pour vous prévenir quand une nouvelle version existe. C'est une simple lecture : rien n'est envoyé, ni identifiant, ni chantier, ni client. Le fichier est signé : l'application ignore tout fichier modifié. GitHub, qui héberge la page, voit l'adresse IP du téléphone comme pour n'importe quelle page web.

## Autorisations

- **Internet** : uniquement pour lire ce fichier des versions.

- **Notifications** : pour le rappel, la veille au soir, des étapes prévues le lendemain. Vous pouvez le désactiver à tout moment.
- **Appareil photo** : l'application ne demande pas cette autorisation ; elle ouvre l'application photo du téléphone quand vous prenez une photo.
- **Micro** : pour enregistrer une note vocale, demandé au premier enregistrement. Le son n'est enregistré que pendant que vous enregistrez, et le fichier reste sur le téléphone.
- **Empreinte, visage ou code du téléphone** : si vous activez le verrouillage, l'application demande au téléphone de vous reconnaître ; elle ne voit ni ne garde votre empreinte, votre visage ou votre code.

## Vos clients

Vous êtes responsable des données de vos clients que vous saisissez (nom, téléphone, adresse). Elles ne sont partagées avec personne par l'application.
